# Security Policy

## Supported Versions

Jellyfish is a build-time Mix compiler task.
It does not run in production and has no runtime dependencies of its own.
Only the latest version published on [Hex.pm](https://hex.pm/packages/jellyfish) receives security fixes.
Older versions are not patched; upgrade to the latest release if a vulnerability is fixed.

## Reporting a Vulnerability

Report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/deployex/jellyfish/security/advisories/new) for this repository.
Do not open a public issue for a security report.

Include, where applicable:

- A description of the vulnerability and its impact.
- Steps to reproduce it.
- The affected version(s).

You should receive an initial response within 7 days.
If the report is confirmed, a fix will be released and the advisory will be published once a patched version is available.
